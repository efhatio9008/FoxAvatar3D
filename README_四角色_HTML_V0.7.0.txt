Fox × Snake × Cat × Dragon Avatar — HTML V0.7.0 (GitHub Pages)
===============================================================
基础：用户上传的 Fox + Snake HTML V0.6.0
角色立绘、动画区域与动作公式：Godot V0.2.5（2026-11-12 用户实测通过）

四位角色：狐女 → 蛇女 → 猫女 → 龙女，左右箭头循环切换。

控制：
  T：尾巴开关（蛇女尾部红色宝石吊坠跟随尾巴）
  H：左右两侧头发飘动开关
  F：外层衣袖、裙摆飘动开关（蛇女和龙女含下层裙摆）
  1、2、3、4：四种发色
  C：四种衣服颜色循环切换
  R：重置平移与缩放
  ← / →：切换角色（支持循环）
  电脑：鼠标拖动人物、滚轮缩放
  手机／平板：单指拖动、双指缩放

移动规则：只有尾巴、左右头发、外层衣袖及裙摆允许自动运动；
脸、肩膀、手臂、手指、大腿、双脚与身体保持静止。
四位角色使用相同功能与说明。无眨眼、无旧 3D 跳转。
每位角色独立记忆发色、衣服颜色、三个动画开关、位置与缩放。

技术：保留 V0.6.0 网站界面与音乐机制，以 WebGL2 或 WebGL1 绘制，
低兼容设备使用 Canvas2D 软件回退。动作与保护区沿用 Godot V0.2.5 逻辑。
为了降低网页加载量，Godot 2.5D 的各张灰度遮罩被无损合并到 RGB 通道：
  motion_a：R=tail, G=hair_left, B=hair_right
  motion_b：R=fabric_motion, G=protect, B=motion_guard
  motion_c：R=hair（换色）, G=outfit（换色）, B=hem_motion
  snake_pendant：R=pendant_motion
精细立绘源文件图像本身未做修改。

网站背景音乐：沿用 V0.6.0 原版 1.mp3 与 bgm.js，无播放器按钮。
如浏览器拦截有声自动播放，访客首次点击、轻触或按键后尝试播放。

部署 GitHub Pages：
1. 解压 ZIP。
2. 将解压后的 index.html、app.js、style.css、bgm.js、1.mp3、
   assets 文件夹及 .nojekyll 直接放入仓库发布根目录（非多嵌套一层）。
3. 设置 GitHub Pages 从该根目录发布。
4. 建议通过 HTTPS 的 GitHub Pages 地址查看；file:// 打开可能限制媒体或图片。
5. 若旧页面仍显示，请强制刷新（Ctrl+F5）或等待浏览器缓存更新。

测试说明：已进行资源路径、ZIP 完整性和浏览器自动化测试；
不同型号手机上的实际流畅度和细微 2.5D 重影仍需用户本人实机查看。
