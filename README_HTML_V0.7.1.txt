Fox x Snake x Cat x Dragon Avatar 2.5D - HTML V0.7.1

SOURCE BASELINE:
User-provided HTML V0.7.0 zip, Fox_Snake_Cat_Dragon_Avatar_HTML_V0.7.0_GitHub_Pages_Full(1).zip.

UPDATES IN V0.7.1:
1. Snowfall on the entire HTML page BACKGROUND, NOT inside the character illustration. Snow is CSS-drawn (no snow artwork files). Snow intensity and falling speed are set by snow.js to medium-high. Snow stays behind all panels, text and character canvas; pointer-events are disabled.
2. Shared magnifier button under the portrait for fox, snake, cat and dragon. Opens an enlarged LIVE animated/color-tinted copy of the entire illustration. Scroll wheel, drag, double-click, + / -, fit, touch pinch, and touch drag. The magnifier has its own zoom/pan and does not change the original view. Press Escape or close X to dismiss.
3. Both desktop and mobile layouts use the same features.

PRESERVED FROM V0.7.0:
Four independent characters; T tail, H both hair sides, F fabric motion; four hair tints, four outfit tints; pan, pinch, zoom, reset; protected stationary body/limbs; snake red pendant and snake/dragon lower hem; character switch arrows; background loop audio with no audio buttons. No blinking and no old 3D.
