Fox × Snake Avatar V0.6.0 — GitHub Pages 整合版
===========================================
以用户上传的 Fox V0.5.3 Web（含背景音乐）及 Snake V0.1 Godot 立绘素材制作。

更新网站：
1. 将本 ZIP 解压。
2. 将解压后的 index.html、app.js、style.css、bgm.js、1.mp3、.nojekyll 和整个 assets 文件夹上传到原 GitHub Pages 仓库的根目录；替换同名文件。
3. 不要上传 ZIP 本身，不要把整套文件额外套进一个文件夹。
4. 等 GitHub Pages 完成部署后，用 Ctrl+F5 或清除手机浏览器缓存刷新网站。

功能：
- 顶部左右箭头切换狐女/蛇女（键盘 ← / → 也可以）。
- 狐女和蛇女各有四款发色、四款衣饰色和独立尾巴动画开关。
- T 尾巴动画 ON/OFF；1-4 发色；C 衣饰换色；R 视角复位；鼠标拖动/滚轮缩放。
- 切换角色会分别记住两个人物当前的颜色、动画开关与拖动缩放状态。
- 每种角色各自加载局部遮罩。蛇尾摆动为 Godot V0.1 相应的 2.5D 局部像素扭曲，不是 3D 骨骼动画。
- 无眨眼功能、无旧 3D 跳转。
- 保留此前网页提供的 1.mp3 背景音乐（若浏览器自动播放被拦截，仍需首次触碰网页）。
- 电脑版、手机版使用同一页面和角色切换功能。
